## syst-base.scm changes

### Add `use-package-modules` (after `use-service-modules`)
```scheme
(use-package-modules
 android  ; android-udev-rules
 cups     ; cups-filters, hplip-minimal
 games    ; steam-devices-udev-rules
 libusb)  ; libmtp
```
nongnu nvidia stays OUT of imports; reference lazily via `(@ (nongnu services nvidia) nvidia-service-type)`
inside `services` (mirrors existing `(@(nongnu packages linux) linux)` in syst-config-linux).

### Replace zero-arg `(def-public (services) ...)` with keyword version + helpers
- `services` keywords (defaults reproduce today: pcscd + openssh + xfce):
  `#:pcscd? #t  #:xfce? #t  #:nvidia? #f  #:cups? #f  #:mtp? #f  #:android? #f  #:steam? #f  #:extra '()`
  Body = `(append (list <openssh>) (if pcscd? ...) (if xfce? ...) (if nvidia? (list (service (@ (nongnu services nvidia) nvidia-service-type)))) (if cups? <cups cfg>) (if mtp? ...) (if android? ...) (if steam? ...) extra)`
- Helper `(nonguix-substitute-urls)` -> nonguix + %default-substitute-urls.
- Helper `(nonguix-authorized-keys #:key peer-key)` -> `(append (if peer-key (list peer-key) '()) (list (local-file "signing-key.guix-science.pub") (local-file "signing-key.nonguix.pub")) %default-authorized-guix-keys)`.
- Helper `(guix-science-authorized-keys)` -> `(append (list (local-file "signing-key.guix-science.pub")) %default-authorized-guix-keys)`.
